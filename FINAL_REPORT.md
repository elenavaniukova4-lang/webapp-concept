# Финальный отчёт по проекту To-Do List

## 📋 Описание системы

Веб-приложение для управления списком задач (To-Do List) с возможностью:
- Добавления новых задач
- Пометки задач как выполненных/невыполненных
- Удаления задач
- Постоянного хранения данных в SQLite

**Технологический стек:**
- Backend: Python 3.10 + Flask 3.0.0
- База данных: SQLite
- Frontend: HTML/CSS + Jinja2 шаблоны
- Контейнеризация: Docker


## 🏗️ Архитектура

Пользователь → Браузер → HTTP-запрос → Flask (app.py) → SQL-запрос → SQLite (tasks.db)
       ↑                                                                 ↓
       └──────────── HTML-ответ ←───────────────────────────────────────┘

### Компоненты системы

Приложение состоит из трёх основных компонентов:

1. **Клиентский слой (Frontend)**  
   - Веб-браузер пользователя  
   - Отображает HTML-страницу с задачами  
   - Отправляет HTTP-запросы на сервер

2. **Серверный слой (Backend)**  
   - Flask-приложение (`app.py`)  
   - Обрабатывает маршруты:  
     - `GET /` — отображение списка задач  
     - `POST /add` — добавление новой задачи  
     - `GET /toggle/<id>` — переключение статуса  
     - `GET /delete/<id>` — удаление задачи

3. **Слой данных (Storage)**  
   - Локальная база данных SQLite (`tasks.db`)  
   - Хранит задачи в таблице `habits` с полями:  
     - `id` — уникальный идентификатор  
     - `title` — текст задачи  
     - `completed` — статус выполнения  
     - `created_at` — время создания

## 🧪 Тестирование

Проект протестирован с помощью функциональных тестов на pytest, покрывающих все основные сценарии (отображение списка задач, добавление,
переключение статуса и удаление), с использованием изолированной временной базы данных и автоматическим запуском в CI.

## 🔒 Безопасность

В проекте реализован многоуровневый подход к обеспечению безопасности на этапе разработки.

**Инструменты анализа**
| Инструмент | Назначение | Результат |
|------------|------------|-----------|

| **Trivy** | Анализ уязвимостей в зависимостях | Обнаружена CVE-2022-1234 в Flask 2.0.0<br>Исправлена обновлением до Flask 3.0.0 |
