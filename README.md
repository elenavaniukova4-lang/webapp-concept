To-Do List 

Описание проекта
To-Do List — это простое веб-приложение на Python, которое помогает пользователю создавать список задач и отмечать их выполнение.

Приложение можно использовать для управления повседневными делами, например:
	•	купить продукты;
	•	сдать отчёт до конца дня;
	•	позвонить другу;
	
Главная идея проекта — дать пользователю удобный инструмент для планирования дня и контроля выполнения задач без лишних отвлекающих элементов.

Основные функции приложения
	1.	Просмотр списка задач
На главной странице пользователь видит все добавленные задачи.
	2.	Добавление новой задачи
Пользователь может добавить новую задачу через простую форму (например: «Решить 5 задач по алгоритмам»).
	3.	Удаление задачи
Если задача больше не актуальна, её можно удалить из списка.
	4.	Отметка задачи как выполненной  
Пользователь может отметить уровень выполнения задачи — она будет визуально выделена (например, зачёркнута).  
  	- задача выполнена  
  	- задача частично выполнена  
 	 - задача не выполнена
	5.Фильтрация задач
Приложение позволяет просматривать:
	•	все задачи,
	•	только текущие,
	•	только завершённые.

Предполагаемая архитектура проекта

Проект имеет простую и понятную структуру, подходящую для начинающих разработчиков.
Он состоит из четырёх основных частей:
1. Python-приложение
Главный файл —  app.py .
Содержит Flask-приложение и маршруты для:
	•	отображения главной страницы;
	•	добавления задачи;
	•	отметки выполнения;
	•	удаления задачи;
	•	фильтрации;
	•	взаимодействия с базой данных.

2. HTML-шаблоны
Папка  templates/  содержит страницы приложения.

Flask использует шаблоны, чтобы подставлять данные из базы данных и показывать их пользователю.

3. Статические файлы

Папка static/ содержит файлы оформления.

В первую очередь это CSS-файл, который отвечает за внешний вид приложения.

4. База данных SQLite

SQLite используется для хранения данных приложения.
База данных хранится в одном файле, например todo.db.

Предполагаемая структура проекта

## Схема базы данных

**Таблица `tasks`** — список задач:
| Поле | Тип | Описание |
|------|-----|----------|
| `id` | INTEGER PRIMARY KEY AUTOINCREMENT | Уникальный идентификатор |
| `title` | TEXT NOT NULL | Название задачи |
| `completed` | BOOLEAN NOT NULL DEFAULT 0 | Статус выполнения (`0` — не выполнено, `1` — выполнено) |
| `created_at` | TIMESTAMP DEFAULT CURRENT_TIMESTAMP | Дата и время создания |

> 💡 База данных `tasks.db` создаётся автоматически при первом запуске на основе файла `database/schema.sql`.

##  Маршруты приложения

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/` | Главная страница — список всех задач |
| POST | `/add` | Добавить новую задачу |
| GET | `/toggle/<int:task_id>` | Переключить статус задачи (выполнена/не выполнена) |
| GET | `/delete/<int:task_id>` | Удалить задачу |

##  Запуск проекта

### 1. Клонировать репозиторий и перейти в папку

```bash
git clone https://github.com/elenavaniukova4-lang/webapp-concept.git
cd webapp-concept/todo-list
```

### 2. Создать виртуальное окружение и установить зависимости

**Windows (PowerShell или cmd):**
```powershell
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

**Linux / macOS:**
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 3. Запустить приложение

```bash
python app.py
```

После запуска в консоли появится сообщение примерно такого вида:

```
 * Running on http://127.0.0.1:5000
```

Откройте в браузере адрес: **http://127.0.0.1:5000**

База данных `tasks.db` будет создана автоматически при первом запуске на основе файла `database/schema.sql`.

### 4. Остановить приложение

Нажмите `Ctrl + C` в терминале.
